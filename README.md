# 대한민국 정치·외교 실시간 브리핑

## 실행
1. 이 폴더에서 `python server.py`
2. 브라우저에서 `http://127.0.0.1:8000`

## 포함 기능
- 국내 정치 / 외교·대외관계 분리
- 오늘·어제·일별·월별 보기
- 중요도·국가·키워드 필터
- 5분마다 `data.json` 자동 확인
- 인쇄 / PDF 저장
- 모바일 대응

## 중요
현재 `data.json`은 기능 확인용 예시 데이터입니다.
실시간 뉴스 수집은 `collector.py`에 공식 RSS/API 또는 허용된 수집 방식을 연결해야 합니다.
브라우저가 닫혀 있어도 자동 수집하려면 서버, GitHub Actions, 클라우드 스케줄러 또는 작업 스케줄러가 필요합니다.

## 권장 운영 주기
- 데이터 수집: 30분마다
- 긴급 상황: 10분마다
- 화면 데이터 확인: 5분마다
- 전날 확정 브리핑: 매일 오전 8시 KST

## 데이터 수정
`data.json`의 `issues` 배열에 동일한 구조로 이슈를 추가하면 화면에 자동 반영됩니다.
